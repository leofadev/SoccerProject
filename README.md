# Soccer Project

Aplicación Expo/React Native para gestionar una liga de fútbol: equipos, jugadores, partidos, tabla de posiciones y goleadores.

## Cómo abrir la app

```bash
npm install
npm run start
```

Después escanea el QR con **Expo Go** o presiona `i`/`a` en la terminal para abrir iOS/Android. Si abres directamente `http://127.0.0.1:8081` en el navegador, Expo muestra un manifiesto JSON de desarrollo; eso es normal y no es la interfaz de la app.

Para web usa:

```bash
npm run web
```

## Checks

npm run typecheck
